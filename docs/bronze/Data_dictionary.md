| Table Name              | Description                          | Contents / Purpose                                                                                                                                                                                                                                                                           |
| ----------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bronze.td_yellow_taxi` | Raw data for yellow taxi trips       | Contains unprocessed trip records, including `vendor_id`, pickup/dropoff times (`pu_datetime`, `do_datetime`), `passenger_cnt`, trip metrics (`trip_distance`, `fare_amount`, `tip_amount`), payment type, and additional charges. This table is the raw source for Silver taxi fact tables. |
| `bronze.td_green_taxi`  | Raw data for green taxi trips        | Contains unprocessed trip records for green taxis, including `vendor_id`, pickup/dropoff times, `trip_type`, location IDs, fare components, and payment type. Used to populate Silver fact tables after cleaning and validation.                                                             |
| `bronze.td_for_hire`    | Raw data for for-hire vehicle trips  | Contains unprocessed for-hire vehicle (FHV) trip data, including `hvfhs_license_num`, `dispatch_base_num`, `trip_distance`, `trip_time`, fare components (`base_passenger_fee`, `tolls_amount`, `tip_amount`), and timestamps. Used for building Silver FHV trip tables.                     |
| `bronze.td_license`     | License lookup for for-hire vehicles | Contains `hvfhs_license_num` and `app_company` to map FHV trips to operating companies. Used to standardize vehicle licensing data.                                                                                                                                                          |
| `bronze.td_taxi_zones`  | Taxi zone lookup                     | Contains NYC taxi zone information with `location_id`, `borough`, `zone`, and `service_zone`. Used to map pickup/dropoff locations in taxi trips to boroughs and zones.                                                                                                                      |
| `bronze.wd_weather`     | Raw weather data                     | Contains daily weather observations per station, including temperature (`temp_mean`, `temp_max`, `temp_min`), precipitation (`prcp_total`), wind, visibility, pressure, and phenomena. Used to enrich trip or event data with weather conditions in Silver layer.                            |
| `bronze.ed_events`      | Raw NYC events data                  | Contains unprocessed events, including `event_name`, start/end times, agency, type, borough, location, street closure type, community board, and police precinct. Used as source for Silver events tables.                                                                                   |
| `bronze.hd_holidays`    | Raw holiday data                     | Contains `holiday_date` and `holiday_name`. Used to populate Silver date/holiday dimension (`hd_date`) for analytics.                                                                                                                                                                        |
