| Column Name           | Data Type    | Description                                                                    | Source Columns                                                                                                                                                                                                 | Transformation                               |
| --------------------- | ------------ | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| taxi_type_id          | TINYINT      | Identifier for the type of taxi: 1 = Yellow, 2 = Green, 3 = Uber, 4 = Lyft.    | `silver.td_yellow_taxi`: all rows → 1, `silver.td_green_taxi`: all rows → 2, `silver.td_for_hire` + `silver.td_license.app_company`                                                                                          | Derived from taxi type                       |
| pu_date_key           | BIGINT       | Pickup date key (surrogate key referencing `hd_date`)                          | `silver.td_yellow_taxi.pu_date_key`, `silver.td_green_taxi.pu_date_key`, `silver.td_for_hire.pu_date_key`                                                                                                                    | None                                         |
| pu_hour               | TIME(0)      | Pickup hour interval                                                           | `silver.td_yellow_taxi.pu_datetime`, `silver.td_green_taxi.pu_datetime`, `silver.td_for_hire.pu_datetime`                                                                                                                    | `time_interval(pu_datetime)`                 |
| do_date_key           | BIGINT       | Drop-off date key (surrogate key referencing `hd_date`)                        | `silver.td_yellow_taxi.do_date_key`, `silver.td_green_taxi.do_date_key`, `silver.td_for_hire.do_date_key`                                                                                                                    | None                                         |
| do_hour               | TIME(0)      | Drop-off hour interval                                                         | `silver.td_yellow_taxi.do_datetime`, `silver.td_green_taxi.do_datetime`, `silver.td_for_hire.do_datetime`                                                                                                                    | `time_interval(do_datetime)`                 |
| trip_time             | INT          | Duration of the trip in seconds                                                | `silver.td_yellow_taxi.pu_datetime`, `silver.td_yellow_taxi.do_datetime` <br> `silver.td_green_taxi.pu_datetime`, `silver.td_green_taxi.do_datetime` <br> `silver.td_for_hire.pu_datetime`, `silver.td_for_hire.do_datetime` | `DATEDIFF(SECOND, pu_datetime, do_datetime)` |
| pu_borough_id         | TINYINT      | Borough of the pickup location (foreign key to `borough`)                      | `silver.td_yellow_taxi.pu_location_id`, `silver.td_green_taxi.pu_location_id`, `silver.td_for_hire.pu_location_id` <br> `silver.td_taxi_zones.borough_id`                                                                    | Join on `pu_location_id`                     |
| do_borough_id         | TINYINT      | Borough of the drop-off location (foreign key to `borough`)                    | `silver.td_yellow_taxi.do_location_id`, `silver.td_green_taxi.do_location_id`, `silver.td_for_hire.do_location_id` <br> `silver.td_taxi_zones.borough_id`                                                                    | Join on `do_location_id`                     |
| trip_distance         | DECIMAL(8,2) | Total distance of the trip in miles/kilometers (depending on source)           | `silver.td_yellow_taxi.trip_distance`, `silver.td_green_taxi.trip_distance`, `silver.td_for_hire.trip_distance`                                                                                                              | SUM                                          |
| distance_bucket_id    | TINYINT      | Categorized distance bucket: 1 = ≤2, 2 = ≤5, 3 = ≤8, 4 = ≤12, 5 = ≤20, 6 = >20 | `silver.td_yellow_taxi.trip_distance`, `silver.td_green_taxi.trip_distance`, `silver.td_for_hire.trip_distance`                                                                                                              | CASE WHEN ...                                |
| fare_amount           | DECIMAL(8,2) | Total fare amount collected for the trip                                       | `silver.td_yellow_taxi.fare_amount`, `silver.td_green_taxi.fare_amount`, `silver.td_for_hire.base_passenger_fee`                                                                                                             | SUM                                          |
| tip_amount            | DECIMAL(8,2) | Tip collected during the trip                                                  | `silver.td_yellow_taxi.tip_amount`, `silver.td_green_taxi.tip_amount`, `silver.td_for_hire.tip_amount`                                                                                                                       | SUM                                          |
| is_tip                | BIT          | Flag indicating whether a tip was given (1 = yes, 0 = no)                      | Same as `tip_amount` columns                                                                                                                                                                                                 | `IIF(tip_amount > 0, 1, 0)`                  |
| tolls_amount          | DECIMAL(8,2) | Total tolls paid during the trip                                               | `silver.td_yellow_taxi.tolls_amount`, `silver.td_green_taxi.tolls_amount`, `silver.td_for_hire.tolls_amount`                                                                                                                 | SUM                                          |
| improvement_surcharge | DECIMAL(8,2) | NYC taxi improvement surcharge                                                 | `silver.td_yellow_taxi.improvement_surcharge`, `silver.td_green_taxi.improvement_surcharge`                                                                                                                                  | SUM                                          |
| congestion_surcharge  | DECIMAL(8,2) | Congestion surcharge applied for trips in NYC                                  | `silver.td_yellow_taxi.congestion_surcharge`, `silver.td_green_taxi.congestion_surcharge`, `silver.td_for_hire.congestion_surcharge`                                                                                         | SUM                                          |
| airport_fee           | DECIMAL(8,2) | Fee for trips to/from airports                                                 | `silver.td_yellow_taxi.airport_fee`, `silver.td_for_hire.airport_fee`                                                                                                                                                        | SUM                                          |
| mta_tax               | DECIMAL(8,2) | MTA tax for yellow/green taxi trips                                            | `silver.td_yellow_taxi.mta_tax`, `silver.td_green_taxi.mta_tax`                                                                                                                                                              | SUM                                          |
| extra                 | DECIMAL(8,2) | Extra charges (miscellaneous fees)                                             | `silver.td_yellow_taxi.extra`, `silver.td_green_taxi.extra`                                                                                                                                                                  | SUM                                          |
| ehail_fee             | DECIMAL(8,2) | e-hail fee for green taxi trips                                                | `silver.td_green_taxi.ehail_fee`                                                                                                                                                                                             | SUM                                          |
| bcf_fee               | DECIMAL(8,2) | Base passenger fee for for-hire trips                                          | `silver.td_for_hire.bcf_fee`                                                                                                                                                                                                 | SUM                                          |
| sales_tax             | DECIMAL(8,2) | Sales tax applied to for-hire trips                                            | `silver.td_for_hire.sales_tax`                                                                                                                                                                                               | SUM                                          |
| total_amount          | DECIMAL(8,2) | Total amount paid for the trip (fare + tip + tolls + fees)                     | `silver.td_yellow_taxi.total_amount`, `silver.td_green_taxi.total_amount`, `silver.td_for_hire.total_amount`                                                                                                                 | SUM                                          |
| trips_cnt             | INT          | Number of individual trips aggregated in the record                            | `silver.td_yellow_taxi.trip_id`, `silver.td_green_taxi.trip_id`, `silver.td_for_hire.trip_id`                                                                                                                                | COUNT                                        |
