| Table Name                      | Description                    | Contents / Purpose                                                                                                                                                                                                                                           |
| ------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `gold.fact_trips`               | Aggregated taxi/FHV trips data | Stores transformed and aggregated trip data from `silver.td_yellow_taxi`, `silver.td_green_taxi`, `silver.td_for_hire`, `silver.td_license`, `silver.td_taxi_zones`. Includes pickup/dropoff keys, distance, fare, tip, surcharges, totals, and trip counts. |
| `gold.fact_weather`             | Daily weather observations     | Stores transformed weather observations from `silver.wd_weather`. Includes temperature, precipitation, visibility, snow depth, wind speed, and weather phenomena flags (`fog`, `rain_or_drizzle`, `hail`, `thunder`, `tornado_or_funnel_cloud`).             |
| `gold.fact_events`              | Aggregated NYC events metrics  | Stores aggregated events data from `silver.ed_events`. Includes agency, event type, borough, street closure type, date key (`gold.dim_date`) and event counts.                                                                                               |
| `gold.dim_taxi_type`            | Taxi type lookup               | Manual table. Maps `taxi_type_id` to taxi types (`Yellow`, `Green`, `Uber`, `Lyft`).                                                                                                                                                                         |
| `gold.dim_borough`              | Borough lookup                 | Stores borough metadata from `silver.borough`. Includes borough name and airport flag (`is_airport`).                                                                                                                                                        |
| `gold.dim_date`                 | Date dimension                 | Stores calendar dates from `silver.hd_date`. Includes `full_date`, `quarter`, `month`, `day`, `is_weekend`, `is_holiday`, and `holiday_name`. Used for time-based joins in trips, weather, and events.                                                       |
| `gold.dim_event_type`           | Event type lookup              | Stores event types from `silver.ed_event_type`. Maps `event_type_id` to descriptive `event_type` names.                                                                                                                                                      |
| `gold.dim_event_agency`         | Event agency lookup            | Stores event agencies from `silver.ed_event_agency`. Maps `agency_id` to human-readable `agency` names.                                                                                                                                                      |
| `gold.dim_street_closure_type`  | Street closure type lookup     | Stores street closure types from `silver.ed_street_closure_type`. Maps `street_closure_type_id` to descriptive `street_closure_type`.                                                                                                                        |
| `gold.dim_trip_distance_bucket` | Trip distance bucket lookup    | Manual table. Maps `distance_bucket_id` to distance ranges (`0-2`, `2-5`, `5-8`, `8-12`, `12-20`, `20+`).                                                                                                                                                    |
