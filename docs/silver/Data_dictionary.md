| Table Name                      | Description                             | Contents / Purpose                                                                                                                                                                                                        |
| ------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `silver.trip_id_seq`            | Sequence for assigning unique trip IDs  | Provides a unique, incremental identifier for all taxi and FHV trips in the Silver layer.                                                                                                                                 |
| `silver.td_yellow_taxi`         | Cleaned and validated yellow taxi trips | Stores transformed and validated yellow taxi trip records with standardized IDs, pickup/dropoff dates (`pu_date_key`, `do_date_key`), location IDs, fare components, and `reject_id` indicating any data quality issues.  |
| `silver.td_green_taxi`          | Cleaned and validated green taxi trips  | Stores transformed and validated green taxi trip records, similar to yellow taxi table, with `trip_type_id` included and `reject_id` for data quality tracking.                                                           |
| `silver.td_for_hire`            | Cleaned and validated FHV trips         | Stores transformed for-hire vehicle trips, including timestamps, location IDs, trip metrics, fare components, shared ride flags, and `reject_id` for quality control.                                                     |
| `silver.td_license`             | FHV license lookup                      | Maps `hvfhs_license_num` to operating company (`app_company`) to standardize FHV trip data.                                                                                                                               |
| `silver.td_taxi_zones`          | Taxi zone lookup                        | Maps `location_id` to boroughs, zones, service zones, and flags for Central Business District (`is_cbd`) and airports (`is_airport`). Used for location dimension in trips.                                               |
| `silver.td_vendor`              | Taxi vendor lookup                      | Maps vendor IDs to human-readable `vendor_name` for both yellow and green taxis.                                                                                                                                          |
| `silver.td_tariff_type`         | Tariff type lookup                      | Maps `tariff_type_id` to descriptive tariff names.                                                                                                                                                                        |
| `silver.td_trip_type`           | Trip type lookup                        | Maps `trip_type_id` to descriptive trip types (for green taxis).                                                                                                                                                          |
| `silver.td_payment_type`        | Payment type lookup                     | Maps `payment_type_id` to descriptive payment methods.                                                                                                                                                                    |
| `silver.wd_weather`             | Cleaned daily weather data              | Stores weather observations per station, including temperature, precipitation, wind, visibility, pressure, and weather phenomena flags (`fog`, `rain_or_drizzle`, etc.). Used to enrich trip and event data.              |
| `silver.ed_events`              | Cleaned and validated NYC events        | Stores transformed events data with numeric IDs for agency, type, borough, street closure type, and `reject_id` for quality issues. Includes start/end datetime and corresponding date keys.                              |
| `silver.hd_date`                | Date dimension                          | Stores all dates with `date_key`, calendar attributes (`quarter`, `month`, `day`), weekend flag (`is_weekend`), holiday flag (`is_holiday`), and `holiday_name`. Used for time-based joins in trips, events, and weather. |
| `silver.borough`                | Borough lookup                          | Maps borough IDs to borough names and airport flags. Used in trips and events to standardize geographic information.                                                                                                      |
| `silver.td_reject`              | Reject reason lookup                    | Maps `reject_id` to description of validation rules violated. Used to tag trips and events with data quality issues.                                                                                                      |
| `silver.qc_conditions`          | Quality control rules                   | Stores conditions applied during ETL for validation, with table names, SQL-like condition expressions, and error messages. Used to generate `reject_id` in trip and event tables.                                         |
| `silver.ed_event_agency`        | Event agency lookup                     | Maps numeric `agency_id` to human-readable `agency_name` for NYC events.                                                                                                                                                  |
| `silver.ed_event_type`          | Event type lookup                       | Maps numeric `event_type_id` to descriptive event types.                                                                                                                                                                  |
| `silver.ed_street_closure_type` | Street closure type lookup              | Maps numeric `street_closure_type_id` to street closure types. Used in events data.                                                                                                                                       |
