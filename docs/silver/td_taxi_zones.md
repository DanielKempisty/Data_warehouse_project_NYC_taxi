| Column Name  | Data Type     | Description                                                                     | Source                            | Transformations                                                                                                                           |
| ------------ | ------------- | ------------------------------------------------------------------------------- | --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| location_id  | SMALLINT      | Unique identifier of the taxi zone.                                             | bronze.td_taxi_zones.location_id  | Direct mapping.                                                                                                                           |
| borough_id   | TINYINT       | Identifier of the borough associated with the taxi zone.                        | bronze.td_taxi_zones.borough      | Derived using CASE expression mapping cleaned borough names to numeric identifiers; specific overrides applied for selected location IDs. |
| zone         | NVARCHAR(255) | Name of the taxi zone.                                                          | bronze.td_taxi_zones.zone         | Removed quotation marks and trimmed whitespace; '"N/A"' replaced with 'Unknown'.                                                          |
| service_zone | NVARCHAR(20)  | Service zone classification used by TLC.                                        | bronze.td_taxi_zones.service_zone | Cleaned text; overridden for selected location IDs (JFK, LaGuardia, Unknown, Outside of NYC).                                             |
| is_cbd       | BIT           | Indicator whether the taxi zone belongs to the Central Business District (CBD). | Derived in silver layer           | Set to 1 for predefined list of CBD location IDs, otherwise 0.                                                                            |
| is_airport   | BIT           | Indicator whether the taxi zone represents an airport location.                 | Derived in silver layer           | Set to 1 for airport-related location IDs (1, 132, 138), otherwise 0.                                                                     |
